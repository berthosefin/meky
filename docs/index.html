Pourquoi Meky ?

Chaque semaine, vous tapez ce genre de code de mémoire : long, facile à oublier, source d'erreurs. Avec Meky, vous ne l'écrivez qu'une seule fois.

  1. Enregistrez la formule une fois

    Retrait MVola
    #111*1*4*1*{NUMERO}*{MONTANT}#

  2. Quand le besoin revient

    {NUMERO}→0340000000
    {MONTANT}→5000
    Aperçu
    #111*1*4*1*0340000000*5000#

  3. Le dialer s'ouvre, pré-rempli

    Plus rien à taper : il ne reste qu'à appuyer sur Appeler.

100 % hors-ligne

Vos codes restent disponibles même sans connexion.

Gratuit et sans pub

Aucune publicité, aucune donnée collectée.

Lancement en une touche

Le code s'ouvre directement dans l'appel USSD.

Comment installer

L'APK n'est pas publié sur Google Play. Sur Android, autorisez l'installation depuis une source inconnue :

  1. Téléchargez le fichier APK avec le bouton ci-dessus.
  2. Ouvrez le fichier depuis les notifications ou le dossier Téléchargements.
  3. Si Android vous le demande, autorisez l'installation depuis votre navigateur ou le gestionnaire de fichiers.
  4. Confirmez avec « Installer », puis ouvrez Meky.

Sur certaines versions d'Android, vous devrez aussi activer « Installer des applications inconnues » dans les réglages.

Meky est une application indépendante, non affiliée à un opérateur.
