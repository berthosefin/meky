Comment installer

L'APK n'est pas publié sur Google Play. Sur Android, autorisez l'installation depuis une source inconnue :

  1. Téléchargez le fichier APK avec le bouton ci-dessus.
  2. Ouvrez le fichier depuis les notifications ou le dossier Téléchargements.
  3. Si Android vous le demande, autorisez l'installation depuis votre navigateur ou le gestionnaire de fichiers.
  4. Confirmez avec « Installer », puis ouvrez Meky.

Sur certaines versions d'Android, vous devrez aussi activer « Installer des applications inconnues » dans les réglages.

Meky est une application indépendante, non affiliée aux opérateurs.
